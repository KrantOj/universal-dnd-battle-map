# Заготовка к следующей версии / Next release notes

Уже сделано и закоммичено в `main` после релиза 1.0.4, но **не выпущено**. При подготовке следующей версии (предложено 1.1.0, т.к. есть изменения поведения) занести в раздел `CHANGELOG.md` (RU и EN), а затем удалить сделанное из этого файла.

## Выпущено в 1.1.0 (опубликовано 2026-11-16)

Обновление с вопросом перед скачиванием, скины 3D-костей, правка скрипта релиза — в CHANGELOG 1.1.0. Живая проверка скачивания обновления и скинов пройдена мастером на других компьютерах.

- Решение мастера: `autoInstallOnAppQuit = true` остаётся (скачанное обновление ставится при выходе из приложения).

## Заморожено (решение мастера, 2026-11-16)

- **Своя GLB-модель костей** (CC0 «Dices» с Blend Swap: цифры в геометрии, вершинные цвета тело/цифры) — ЗАМОРОЖЕНО, вернуться позже по просьбе мастера. Файл: `D:\downloads\Dices blendswap.glb`.

## Отклонено

- Превью броска в окне мастера — не нужно.
- Переключатель «3D / плоские кубики» в настройках — не нужен.

## Перед выпуском

1. Поднять версию в `package.json` и `package-lock.json`, написать раздел `## [X.Y.Z]` в `CHANGELOG.md`.
2. `git push origin main`, затем `npm run release`, проверить portable, `npm run release -- --skip-build --publish`.
