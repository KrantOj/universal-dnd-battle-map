# Заготовка к следующей версии / Next release notes

Уже сделано и закоммичено в `main` после релиза 1.0.4, но **не выпущено**. При подготовке следующей версии (предложено 1.1.0, т.к. есть изменения поведения) занести в раздел `CHANGELOG.md` (RU и EN), а затем удалить сделанное из этого файла.

## Войдёт в следующий релиз

- **Обновление спрашивает разрешения** (коммит `e92f3fd`). Установленная версия больше не скачивает обновление сама: плашка и «О программе» показывают «Доступна версия X» и кнопку «Скачать обновление»; установка — по «Установить и перезапустить». Portable без изменений. Файлы: `src/main/updater.js`, `ipc.js`, `preload.js`, `update-ui.js`, `about.js`, `about.html`, локали.
  - [ ] Живая проверка скачивания возможна только когда выйдет версия новее установленной — проверить на релизе после этого.
  - [ ] Решение: оставлять ли `autoInstallOnAppQuit = true` (сейчас скачанное ставится при выходе без отдельного нажатия).
- **Скрипт релиза** (коммит `7d12d5c`): в GitHub уходит только blockmap текущей версии (внутреннее, в CHANGELOG для пользователей не нужно).

- **Скины 3D-костей** (не закоммичено на момент записи): формат `udbm-dice-skin/1` (`skin.json` + PNG/JPG/WebP), 5 встроенных скинов (Классика, Кость, Обсидиан, Изумруд, Тайная магия), свои скины из папки `userData/dice-skins/`, выбор и пробный бросок в «Настройки → Кости (3D)», скин уходит игрокам в сообщении `roll`. Инструкция по Blender: `docs/DICE-SKINS.ru.md`/`.en.md`, пример: `docs/dice-skin-example/`. Файлы: `src/main/diceskins.js`, `src/renderer/js/dice-skin.js`, `dice3d.js`, `settings.js`, `player.js`, IPC `diceSkins:*`.
  - [ ] Живая проверка в приложении (настройки → превью, выбор скина → бросок в окне игроков, папка скинов).
  - [ ] Для CHANGELOG: RU и EN.

## Идеи на потом (не начато)

- Своя GLB-модель костей (CC0 «Dices» с Blend Swap: цифры в геометрии, вершинные цвета тело/цифры) — решение за мастером.
- Переключатель «3D-кубики / плоские» в настройках, учёт `prefers-reduced-motion`.
- Превью броска в окне мастера (мастер сейчас видит только лог).

## Перед выпуском

1. Поднять версию в `package.json` и `package-lock.json`, написать раздел `## [X.Y.Z]` в `CHANGELOG.md`.
2. `git push origin main`, затем `npm run release`, проверить portable, `npm run release -- --skip-build --publish`.
