# Скины костей (3D)

Скин меняет вид 3D-костей: цвет и материал корпуса, текстуру, цвет и свечение цифр. Скин — это **папка с файлом `skin.json` и несколькими картинками**. Никакого кода: файлы безопасно передавать друзьям.

Выбрать скин: **Настройки → Кости (3D)**. Выбранный скин видят игроки. Там же кнопка «Бросить для примера».

## Куда класть

Кнопка **«Открыть папку скинов»** (Настройки → Кости) открывает нужную папку. В ней у каждого скина своя подпапка:

```
dice-skins/
  Мой камень/
    skin.json
    body.png
    body_normal.png
```

Положили папку → в настройках нажмите **«Обновить список»** → скин появится в группе «Свои». Папки без читаемого `skin.json` пропускаются.

Готовый образец: папка [docs/dice-skin-example](dice-skin-example/) (скопируйте её в папку скинов).

## skin.json

Все поля необязательны: чего нет, то берётся «как у Классики». Ошибки в значениях заменяются значениями по умолчанию (приложение не падает).

```json
{
  "format": "udbm-dice-skin/1",
  "name": { "ru": "Камень", "en": "Stone" },
  "body": {
    "color": "#ffffff",
    "metalness": 0.05,
    "roughness": 0.8,
    "map": "body.png",
    "normalMap": "body_normal.png",
    "roughnessMap": "body_rough.png",
    "mapScale": 1.0,
    "normalScale": 1.0
  },
  "edges":   { "color": "#c9c0a8", "opacity": 0.5 },
  "numbers": { "color": "#ffe9a8", "outline": "#1a1208", "glow": "#ff9b2e", "size": 1.0, "font": "Georgia" }
}
```

| Поле | Что делает | Допустимо |
|---|---|---|
| `name` | Название в списке: строка или `{ "ru": …, "en": … }` | до 40 символов |
| `body.color` | Цвет корпуса. Если есть `map`, цвет лишь **оттенок** (умножается на картинку), по умолчанию тогда белый | `#rrggbb` |
| `body.metalness` | Металличность: 0 — камень/кость, 1 — металл | 0…1 |
| `body.roughness` | Шероховатость: 0.05 — зеркальный глянец, 1 — матовый | 0.05…1 |
| `body.map` | Картинка цвета (диффуз) | PNG/JPG/WebP, имя файла **без подпапок** |
| `body.normalMap` | Карта рельефа (normal map) | то же; формат OpenGL (как в Blender по умолчанию) |
| `body.roughnessMap` | Карта шероховатости (чёрно-белая, множится на `roughness`) | то же |
| `body.mapScale` | Масштаб текстуры: больше число — мельче узор | 0.1…10 |
| `body.normalScale` | Сила рельефа; **минус переворачивает** (если рельеф «вдавлен» вместо «выпуклого», у карт формата DirectX) | −5…5 |
| `edges.color`, `edges.opacity` | Тонкие линии на рёбрах | цвет, 0…1 |
| `numbers.color` | Цвет цифр | `#rrggbb` |
| `numbers.outline` | Цвет контура вокруг цифр (читаемость) | `#rrggbb` |
| `numbers.glow` | Цвет свечения цифр; пусто — без свечения | `#rrggbb` или `""` |
| `numbers.size` | Размер цифр | 0.6…1.3 |
| `numbers.font` | Шрифт цифр (должен быть установлен в Windows) | название шрифта |

Лимиты: `skin.json` до 64 КБ, каждая картинка до 6 МБ (на практике хватает 512×512 или 1024×1024), имена картинок без `/`, `\`, `..`.

Как текстура ложится на кость: у моделей нет UV-развёртки, поэтому приложение само проецирует текстуру **на каждую грань отдельно** (плоско). Середина грани приходится на середину текстуры, а стык «плиток» уходит далеко от цифры, поэтому **при `mapScale` примерно до 1.4 текстура не обязана быть бесшовной**. Для большего `mapScale` делайте текстуру бесшовной.

## Как сделать скин в Blender

Blender нужен для картинок (текстур) и для подбора материала. Сам `skin.json` пишется в блокноте.

### Шаг 1. Подберите цвет и блеск (ровно как в `skin.json`)

1. Откройте любой кубик/сферу в Blender, вкладка **Shading**, режим просмотра **Material Preview**.
2. В узле **Principled BSDF** подберите **Base Color**, **Metallic** и **Roughness**.
3. Эти числа переносите в `skin.json`:
   - `Metallic` → `body.metalness`, `Roughness` → `body.roughness`;
   - цвет: в окне выбора цвета вкладка **Hex** → значение вроде `2B3A56` → в json `"#2b3a56"`.
   Внешний вид близок к Blender, но не идентичен (другой рендерер). Проверяйте результат кнопкой «Бросить для примера».

### Шаг 2. Сделайте текстуру (картинку) для корпуса

Выберите один из способов.

**Способ А: скачать готовую (быстрее всего, без Blender).** На сайтах с лицензией CC0 (ambientCG, Poly Haven) возьмите набор PBR 1K в формате PNG: файлы `…_Color` → `body.png`, `…_NormalGL` → `body_normal.png`, `…_Roughness` → `body_rough.png`. Берите именно **NormalGL** (OpenGL), а не NormalDX; если рельеф всё равно «наоборот», поставьте `"normalScale": -1`.

**Способ Б: нарисовать материал в Blender и «запечь» в картинку.**
1. Новый файл, удалите куб, **Add → Mesh → Plane**.
2. Верхнее меню → **Render Properties** → **Render Engine: Cycles**.
3. Вкладка **Shading**: у плоскости новый материал, соберите узлами рисунок (например, **Noise Texture** + **Voronoi** → **ColorRamp** → в Base Color; для рельефа **Bump** → в Normal).
4. Добавьте узел **Image Texture** → **New** → размер **1024 × 1024**, назовите `body` → **не подключайте** узел, просто кликните по нему, чтобы он был выбран.
5. **Render Properties → Bake**: **Bake Type: Diffuse**, снимите галочки **Direct** и **Indirect**, оставьте **Color** → **Bake**.
6. Окно **Image Editor** → выберите картинку `body` → **Image → Save As…** → `body.png`.
7. Для рельефа и блеска повторите запекание: **Bake Type: Normal** → сохраните `body_normal.png`; **Bake Type: Roughness** → `body_rough.png`.

**Способ В: Texture Paint.** Вкладка **Texture Paint**, создайте текстуру 1024×1024 и рисуйте прямо в Blender (потёртости, руны, узоры). Сохраните как `body.png`.

Заметки по картинкам: квадратные (512 или 1024 пикселя), PNG; не делайте на текстуре цифр: цифры рисует приложение.

### Шаг 3. Соберите папку и проверьте

1. Создайте папку скина, положите `skin.json` и картинки (имена в json должны совпадать с файлами).
2. Приложение → **Настройки → Кости (3D) → «Обновить список»** → выберите скин → **«Бросить для примера»**.
3. Подгоняйте значения: изменили `skin.json` → снова «Обновить список» (картинки перечитываются).

## Если что-то не работает

| Симптом | Причина |
|---|---|
| Скина нет в списке | в папке нет `skin.json` или он с ошибкой JSON (запятая, кавычки): проверьте, например, в любом онлайн-валидаторе JSON |
| Текстура не видна | имя файла не совпадает, файл не PNG/JPG/WebP, больше 6 МБ, лежит в подпапке |
| Всё слишком тёмное/цветное | при текстуре `body.color` умножается на картинку: поставьте `"#ffffff"` |
| Рельеф вдавлен вместо выпуклого | карта формата DirectX: `"normalScale": -1` |
| Цифры плохо видны | задайте `numbers.outline` контрастного цвета или `numbers.glow` |
| Скин не загрузился | приложение возвращает «Классику» и пишет причину в журнал |

## Чего скины пока не умеют

Свои формы костей и собственные цифры-картинки в версии 1 формата не поддерживаются. Это возможное развитие (загрузка своих GLB-моделей).

Пример скина создаётся скриптом `node scripts/make-example-skin.js`.
