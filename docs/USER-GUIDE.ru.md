# Universal DnD Battle map — руководство пользователя

Universal DnD Battle map — программа для мастера D&D 5e: боевая карта с сеткой, туманом войны, дверями и токенами на одном экране и «чистое» окно для игроков на втором. Рядом — инициатива, HP, кубики, показ картинок игрокам, фоновая музыка и редактор карт. Всё работает без интернета.

*English version: [USER-GUIDE.en.md](USER-GUIDE.en.md).*

## 1. Установка

Программа распространяется для Windows (64 бита) в двух вариантах — скачайте нужный со страницы **Releases** на GitHub (`KrantOj/universal-dnd-battle-map`):

| Вариант | Файл | Когда выбрать |
|---|---|---|
| **Установщик (NSIS)** | `Universal DnD Battle map Setup <версия>.exe` | Обычная установка: выбор папки, ярлык на рабочем столе, удаление через «Установку и удаление программ». Рекомендуется. |
| **Портативная** | `Universal DnD Battle map <версия> portable.exe` | Без установки: запускается из любой папки, в том числе с флешки. Ничего не прописывает в системе. |

**Предупреждение SmartScreen.** Файлы пока не подписаны сертификатом издателя, поэтому при первом запуске Windows может показать синее окно «Windows защитила ваш компьютер». Нажмите **«Подробнее» → «Выполнить в любом случае»**. Это нормально для неподписанных программ; скачивайте файлы только со страницы релизов проекта.

Настройки приложения и профили кампаний хранятся в папке профиля пользователя (`%APPDATA%\Universal DnD Battle map`), а сцены, библиотека токенов и закрепления — в «папке данных» каждой кампании (по умолчанию `Документы\Universal DnD Battle map\<название кампании>`). Ваши карты, картинки и музыка остаются там, где лежат: программа читает их из выбранных папок и ничего не удаляет.

Удаление: установщик — через «Параметры → Приложения»; портативную версию достаточно удалить как обычный файл (данные кампаний останутся в `Документах`).

## 2. Первый запуск: мастер

Если кампаний ещё нет, откроется мастер первого запуска. Любой шаг, кроме названия и итогового, можно пропустить («Пропустить»), всё меняется потом в «Настройках».

1. **Язык** — русский или English. Язык по умолчанию определяется по языку Windows; при смене страница тут же перезагружается.
2. **Название кампании** — видно только вам.
3. **Папка данных** — для сцен, библиотеки токенов и кэша. Если не менять, создаётся `Документы\Universal DnD Battle map\<название>`. Если вы выберете папку, где уже лежат чужие файлы (например, хранилище заметок), программа предупредит и предложит создать вложенную подпапку; она трогает только собственные файлы.
4. **Папка с картами** — где лежат карты боя (`*.map.json` и их картинки).
5. **Категории «Показа»** — папки с картинками для показа игрокам: портреты, гербы, иллюстрации. Название категории любое; можно включить «с подпапками».
6. **Музыка** — папка с аудио; подпапки станут плейлистами.
7. **Журнал боя** — вести ли журнал и в какую папку сохранять заметки (`.md`).
8. **Окно игроков** — открывать ли его само при запуске, если подключён второй монитор.
9. **Готово** — проверьте сводку и нажмите «Создать кампанию».

Мастер можно запустить снова: **Файл → Мастер первого запуска** (или «Новая кампания…» в «Настройках») создаст ещё одну кампанию.

## 3. Кампании

Кампания — это набор настроек: папки, категории «Показа», музыка, журнал боя и окно игроков; плюс её собственные сцены и библиотека токенов.

**Файл → Кампании…** открывает менеджер: открыть, переименовать, дублировать (копия настроек), удалить, экспортировать и импортировать. При удалении профиль убирается из программы, а ваши карты, картинки и журналы остаются на диске; отдельным флажком можно удалить и файлы приложения в папке данных (сцены, библиотеку, закрепления, миниатюры) — чужие файлы в этой папке не затрагиваются.

Если кампаний несколько, при запуске программа спросит, какую открыть. **Файл → Кампания: настройки** (или кнопка ⚙ на панели) открывает окно настроек текущей кампании — изменения применяются сразу. Если сменить папку данных, программа предложит перенести старые данные (сцены, библиотеку, закрепления) в новую папку.

## 4. Карты: папка и импорт

Боевая карта — это файл `<имя>.map.json` и PNG-картинка рядом (формат описан в [MAP-FORMAT.md](MAP-FORMAT.md)). Такие карты умеет создавать редактор из раздела 5, а также внешние инструменты.

- Кнопка **📂 Карты** показывает список карт из папки карт кампании. Последняя открытая отмечена «(последняя)».
- Кнопка **⬇ Импорт карты** (или **Файл → Импорт карты…**) копирует выбранный `map.json` и его PNG в папку карт и открывает карту. Если картинка не нашлась рядом, программа предложит выбрать её вручную.
- Файлы `*.map.json` и `*.png` можно просто **перетащить на окно программы** — результат тот же.
- Если папка карт не задана, программа предложит выбрать её при первом импорте.
- Если файл карты изменился на диске (например, вы поправили его в редакторе), появится панель «Карта изменилась на диске» с кнопкой «Перезагрузить»: токены и туман при этом сохраняются.

Для каждой карты хранится своя **сцена**: токены, туман, двери, раунд. Она сохраняется автоматически и восстанавливается при следующем открытии карты.

## 5. Редактор карт

Кнопка **✏ Редактор** (или **Файл → Новая карта из картинки…** / **Открыть в редакторе**) открывает отдельное окно, в котором из обычной картинки (JPG, PNG, WEBP) делается боевая карта.

1. **Новая из картинки…** — выберите картинку и введите название; карта создаётся в своей подпапке внутри папки карт (но не раньше первого сохранения). Можно и открыть существующую карту (**Открыть…**).
2. **Сетка (G)** — размер клетки в пикселях, смещение, число колонок и строк, футов в клетке. Помогают «Обвести клетку» (рамка одной клетки, тяните за углы) и «N клеток по горизонтали» (отметьте две точки и укажите, сколько клеток между ними). Стрелки сдвигают сетку на 1 px (Shift — на 10), Ctrl+стрелки меняют размер клетки.
3. **Стены (W)** — ломаная по клеткам: клики ставят точки (с привязкой к углам и серединам граней, Alt — без привязки), Enter или двойной клик заканчивает, Esc отменяет, Backspace убирает последнюю точку.
4. **Двери (D)** — клик по стене делает дверь шириной в клетку; клик по двери убирает её. Можно задать «открыта по умолчанию».
5. **Местность (T)** — кисть, прямоугольник или заливка: обычная, труднопроходимая, вода, яма, препятствие, непроходимо. Заливка не переходит через стены.
6. **Высота (H)** — высота клеток в футах (задать или прибавить).
7. **Выбор (V)** — перетаскивание точек стен, удаление точек и отрезков (Delete; Shift — вся стена), добавление точки двойным кликом по отрезку.

Сверху: **Сохранить** (Ctrl+S — с проверкой), **Проверка** (список замечаний: сетка выходит за картинку, дверь не на стене и т. п.), **Проверить в бою** (сохранить и открыть карту в окне мастера), отмена/повтор (Ctrl+Z / Ctrl+Y), **По размеру**, переключатели слоёв. Несохранённая работа автоматически пишется в черновик и будет предложена к восстановлению при следующем открытии редактора.

## 6. Два экрана и окно игроков

**🖥 Окно игроков** открывает отдельное окно для зрителей: туман, токены, раунд и очередь ходов, показанные картинки, результаты кубиков. Оно не содержит ваших заметок и скрытых токенов.

- Если подключён второй монитор, окно открывается на нём в полный экран; монитор можно выбрать в настройках. Если монитор один — это обычное окно, которое можно перетащить.
- Автооткрытие при запуске включается в настройках кампании («Окно игроков»); там же — «Полный экран на втором мониторе».
- В окне игроков **двойной клик или F** переключает полный экран.
- Если монитор подключили или отключили, окно переезжает само.
- Блок **«Вид игроков»**: «Вся карта», «Открытое» (по открытому туману), «Как у меня» (повторяет ваш масштаб и сдвиг) и «Отправить мой вид» (однократно).

## 7. Токены, туман, двери, линейка

**Панель справа — «Токены на карте» и «Библиотека».** Токены создаются кнопкой **+ Токен** (имя, метка до 3 символов, цвет или картинка, тип — Игрок / Союзник / Враг / Нейтральный, размер — от Среднего 1×1 до Громадного 4×4, скорость, обзор, КД, максимум HP, модификатор инициативы, команда) или берутся из библиотеки (клик ставит токен на карту). Правый клик по токену — меню: статус, скрыть от игроков, редактировать, дублировать, **«В библиотеку»**. Кнопка **Поставить партию** ставит всех игроков-шаблонов вокруг выбранной клетки. Библиотеку можно экспортировать и импортировать в файл.

**Статусы:** в норме, без сознания, недееспособен, убит. HP ≤ 0 выставляет статус автоматически.

**Инструменты** (панель сверху, клавиши в скобках):

- **✋ Выбор (V)** — выбор и перетаскивание токенов; пока тянете, показывается линейка с затратой футов, учётом труднопроходимой местности, высоты, стен и закрытых дверей. **Shift** — свободное перемещение без ограничений; **Ctrl+Z** — отменить перемещение; стрелки сдвигают выбранный токен на клетку.
- **🌫 Открыть (R)** / **🌑 Скрыть (H)** — кисть тумана (размер 1/3/5), **▭ Область (Shift+R)** — открыть прямоугольником. «Открыть всё» / «Скрыть всё» — вся карта сразу.
- **👁 Открыть обзор игроков** — открыть туман там, где сейчас видят токены партии и союзников (у каждого токена свой «Обзор» в футах). Флажок «Автооткрытие тумана» делает это автоматически, когда токен партии или союзника ставится или перемещается.
- **🚪 Двери (D)** — клик рядом с дверью открывает/закрывает её. Закрытые двери и стены не пропускают токены.
- **📍 Пинг** — метка на карте, видимая игрокам (Alt+клик работает в любом инструменте).
- **Линейка видна игрокам** — отдельный переключатель в панели настроек сцены; там же сетка и подписи (отдельно у мастера и у игроков), «Диагонали» (правило подсчёта) и экспорт/импорт сцены.
- Колесо — масштаб к курсору; панорама — пробел + левая кнопка, средняя или правая кнопка мыши; клавиша `?` или кнопка **?** показывает все горячие клавиши.

## 8. Бой: инициатива, HP, счётчики, кубики

Панель **«Бой»** справа.

1. Поставьте токены. У каждого есть поля: инициатива, «мод» (модификатор), КД, HP / «макс», команда.
2. **🎲 Бросить инициативу** бросает d20 + модификатор всем, у кого её ещё нет (Shift — всем заново). Кубик 🎲 у токена бросает только ему. Инициативу можно вписать вручную.
3. **▶ Начать бой** сортирует участников и подсвечивает первого. **Следующий ход (N)** переходит дальше; в конце круга начинается новый раунд (счётчики с «−1/+1 каждый раунд» срабатывают сами). **■ Конец** заканчивает бой, **⇅ Сортировать** — пересортировать, **Сбросить** — убрать инициативу у всех.
4. **«Очередь ходов на экране игроков»** — показывать ли игрокам порядок ходов.
5. **HP.** В поле «−5 / +5» вводят: `−5` — урон, `+5` — лечение, `20` или `=20` — задать значение. Нужно, чтобы был задан «макс». При HP ≤ 0 статус ставится сам. «Источник урона» определяет, кому записывать нанесённый урон и убийства («по ходу» — тому, чей сейчас ход).
6. **Счётчики** («+ Счётчик»): факел, концентрация, заряды; привязываются к токену и могут уменьшаться или увеличиваться на 1 каждый раунд. Когда счётчик доходит до нуля, появляется уведомление.
7. **Кубики.** Панель «Кубики»: клик по кубику добавляет его в формулу, ±1 — модификатор, **Преим.** / **Помеха** — бросок d20 с преимуществом/помехой. Формулу можно писать руками: `2d6+3`, `d20+5`, `4d6dl1` (отбросить младший), `2d20kh1` (оставить старший), `2d20kl1`, `d20 adv`, `d20 dis`. Буква `д` и слова `преим` / `помеха` тоже понимаются — независимо от языка интерфейса. Флажок «Показывать игрокам» выводит результат на их экран (критические 20 и 1 — отдельной надписью); клик по записи журнала бросков показывает её игрокам.

## 9. Показ картинок игрокам

Кнопка **🖼 Показ** открывает панель с вкладками: **★ Сессия** (закреплённые) и по одной вкладке на каждую категорию из настроек. Клик по миниатюре показывает картинку на экране игроков, повторный клик — убирает; ✕ на плашке сверху (или клавиша **B**) возвращает карту. Звёздочка ☆ закрепляет картинку во вкладке «Сессия». Есть поиск по названию, подпись внизу экрана игроков («Подпись игрокам») и пересканирование папки. Если боевая карта не нужна, в списке карт есть режим **«🖼 Только показ»**.

## 10. Музыка и устройство вывода

Панель **«Музыка»** в правой колонке. Укажите папку с музыкой (в настройках или кнопкой в панели): её **подпапки — плейлисты**, файлы прямо в папке попадают в «Без папки». Поддерживаются mp3, ogg, wav, flac, m4a, aac, opus.

- Выберите плейлист, затем ▶/пауза, предыдущий/следующий трек, перемешивание (каждый трек один раз за круг), повтор (выключен / плейлист / трек), ползунок позиции и громкости.
- **Переход** — плавный кроссфейд между треками (выкл. или несколько секунд).
- **Вывод** — устройство, на которое идёт звук. Выберите колонки или наушники; выбор запоминается. Если устройство пропало, музыка переходит на системное, а при возвращении устройства возвращается на него. Музыку слышит только мастер — игроки в окне игроков её не слышат.
- **Горячие клавиши музыки** (в «Настройках»): по умолчанию Ctrl+Пробел — пауза, Ctrl+←/→ — трек, Ctrl+↑/↓ — громкость. Нужны Ctrl или Alt (либо F2–F12), чтобы не пересекаться с клавишами карты; пока курсор в поле ввода, они не срабатывают.

## 11. Журнал боя

Пока идёт бой, программа записывает ходы, урон, лечение, смены статусов и убийства. Кнопка **💾 Сохранить бой** создаёт заметку `.md`: участники (КД, макс. HP, полученный/нанесённый урон, убийства, исход), «кто кого убил» и хронология по раундам. Заметка пишется на языке интерфейса. Папка для заметок задаётся в настройках («Журнал боя»); если её нет, программа предложит выбрать папку или «Сохранить как…».

Если бой не сохранён, при следующем бое или после перезапуска программа предложит сохранить его. Журнал можно отключить совсем — флажок «Вести журнал боя и сохранять заметки»; тогда кнопки сохранения не будет. Перед «Очистить сцену» программа тоже предлагает сохранить бой.

## 12. Экспорт и импорт кампании

В **Файл → Кампании…** есть кнопки **Экспорт…** и **Импорт…**. Экспорт упаковывает кампанию в один файл `.udbm`, который можно перенести на другой компьютер:

- всегда: настройки (пути заменяются метками), сцены, библиотека токенов, закрепления «Показа»;
- по выбору: карты, картинки «Показа», журналы боёв (миниатюры не включаются).

Перед экспортом показывается размер и примерное время; во время работы программа может не отвечать — не закрывайте её. При **импорте** выберите файл `.udbm`: можно создать новую кампанию (укажите для неё папку данных — карты, картинки и журналы распакуются в её подпапки) или заменить содержимое текущей (одноимённые сцены, библиотека и закрепления перезапишутся, остальное останется).

## 13. Язык интерфейса

Язык — русский или English — переключается в **«Настройках»** («Язык интерфейса») и на первом шаге мастера. Это настройка всего приложения, а не одной кампании. Перезапускать программу не нужно: сцена сохраняется, окна мастера, редактора и игроков перезагружаются, меню пересобирается. Если переключить язык посреди боя, после перезагрузки программа предложит сохранить «оставшийся» бой. Формулы кубиков работают на обоих языках независимо от выбранного.

## 14. Сообщить о проблеме

**Справка → Сообщить о проблеме…**: опишите, что вы делали и что получилось, и нажмите «Собрать отчёт». Программа сохранит архив с логами, вашим описанием и версиями программ (без сцен, карт и картинок; имя вашей папки пользователя заменяется на `<HOME>`), откроет его папку и предложит перейти на страницу **Issues** на GitHub — приложите файл к обращению. Куда отправлять отчёт, решаете вы. **Справка → Папка логов** открывает папку с логами, **О программе** показывает версию.

## 15. Необязательно: библиотека токенов

Готовую библиотеку токенов (монстры, NPC и т. д.) можно скачать отдельно — она не входит в установщик:

1. Откройте https://github.com/KrantOj/universal-dnd-battle-map/releases/tag/extras-tokens-1 и скачайте файл библиотеки.
2. Переименуйте его в **`Библиотека токенов.vtt.json`**.
3. Положите файл в **папку карт** вашей кампании.
4. Откройте программу: на панели «Библиотека» нажмите **Импорт библиотеки** и выберите этот файл. Токены появятся в списке с поиском по имени и категории.

## 16. Горячие клавиши

Полный список всегда доступен по клавише **?**. Основное:

| Клавиши | Действие |
|---|---|
| V / R / H / Shift+R / D | Выбор / открыть кистью / скрыть кистью / открыть областью / двери |
| 1 / 3 / 5 | Размер кисти |
| Alt+клик | Пинг |
| Shift при перетаскивании | Свободное перемещение без линейки |
| Стрелки | Сдвиг выбранного токена на клетку |
| Ctrl+Z | Отменить перемещение |
| Delete | Удалить выбранный токен |
| N | Следующий ход в бою |
| B | Вернуть игрокам карту (убрать показ) |
| Колесо / пробел+мышь | Масштаб / панорама |
| 0 | Вписать карту в окно |
| Esc | Отмена (размещение, перетаскивание, меню, панель «Показа») |
| F или двойной клик (окно игроков) | Полный экран |
| Ctrl+Пробел, Ctrl+←/→/↑/↓ | Музыка (настраивается) |
